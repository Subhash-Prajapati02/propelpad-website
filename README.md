# Premium Client Website

A modern, responsive website built to deliver a premium user experience through elegant design, interactive elements, and smooth animations.

## Features

- Premium, responsive UI/UX
- Modern layouts and typography
- Smooth scrolling and animations
- Interactive components and transitions
- Optimized desktop, tablet, and mobile experience
- Performance-focused implementation

## Technology Stack

- React
- TypeScript
- Vite
- Tailwind CSS

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Production Build

```bash
npm run build
```

## Project Structure

- `src/` — Application source code and components
- `public/` — Static assets
- `package.json` — Dependencies and scripts
